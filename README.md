# Imposter Game Telegram Bot

A Telegram bot for playing the Imposter game in groups. 

Built with Node.js and Telegraf. Runs inside a Docker container.

## Local Development

1. Install dependencies:
   ```bash
   npm install
   ```
2. Create a `.env` file with your `TELEGRAM_BOT_TOKEN`.
3. Start the bot:
   ```bash
   node bot.js
   ```
